## 批次 C — TUI 增强 + vim(2 项,较大)

### C1. 真 vim 模式(输入框 modal 编辑)
- **状态机**:Repl.tsx ~153 加 `vimEnabledRef`(是否开启)+ `vimModeRef`('normal'|'insert',默认 insert)。用 ref 而非 state(useInput 闭包读不到最新 state,需配套 useState 同步渲染)
- **/vim 命令**:切换 vimEnabledRef,ALL_COMMANDS 加条目
- **useInput 分发**(~1900 行,权限弹窗之后、Ctrl+C 之前):
  - vimEnabled 且 mode=normal → 走 vim 分支:hjkl 移光标 / w b 词移动 / 0 $ 行首尾 / gg G / i a o I A O 进 insert / x dd dw 删 / Esc 留 normal
  - vimEnabled 且 mode=insert → 走现有逻辑,但 Esc 改为"切 normal"(不退出程序);双击 Esc 才退出

- **回车**:normal 模式回车不提交(或映射为光标移动)
